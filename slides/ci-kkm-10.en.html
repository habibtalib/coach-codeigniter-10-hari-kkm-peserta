DEFINITION OF DONE

“Done” means…

  • AC pass manual testing
  • Validation & access on the server
  • Status recorded in status_logs
  • PHPUnit passes · no .env committed
  • You can explain every line
AI DISCIPLINE

Day 1 · S2 — Technique

A structured interview in four phases

  1. ContextUnderstand the current process: “How do staff get an OKU slot today?”
  2. ProblemsFind pain points: “What causes complaints most often?”
  3. DetailsRules, data, exceptions: “What is the maximum time someone can hold a slot?”
  4. ConfirmationRepeat back your understanding: “So an applicant can only have one active booking — is that right?”
💡
Ask “tell me about the last time…”, not “would you like…”. Real stories reveal the exceptions.
⚠️
Record the owner's own words first. Technical solutions come later.

Demo 5 minit: tanya seorang peserta tentang "proses mohon cuti" menggunakan 5W1H. Kemudian anda sendiri berlakon sebagai pemilik sistem, Puan Noraini — jawab hanya apa yang ditanya. Setiap peserta bergilir 1 soalan dan merekod pain point dalam docs/temubual-tlk.md (Lab 1.2).

Day 2 · S3 — Acceptance criteria

Given / When / Then: testable requirements

URS · AC-TLK-01gherkin
# AC-TLK-01 · No overlapping bookings (BR-TLK-01)
Given slot "A-01" mempunyai tempahan approved
      dari 2026-10-05 hingga 2026-10-12
When  pemohon memohon slot "A-01"
      dari 2026-10-10 hingga 2026-10-15
Then  permohonan ditolak dengan mesej
      "Slot tidak tersedia bagi tarikh dipilih"
And   tiada rekod baharu dalam slot_bookings

Given

The starting state of the data — specific & synthetic.

When

A single user action only.

Then / And

An observable result — message, record, status.

Day 5 · S3 — Reference numbers

ReferenceNumberService: TLK-2026-0001 without race conditions

app/Services/ReferenceNumberService.phpphp
class ReferenceNumberService
{
    public function __construct(private BaseConnection $db) {}

    public function next(string $prefix): string   // 'TLK' | 'PAS'
    {
        $year = (int) date('Y');
        $this->db->transException(true)->transBegin();   // error → exception
        try {
            $row = $this->lock($prefix, $year);              // 1. FOR UPDATE FIRST
            if ($row === null) {                             // 2. new year only
                $this->db->table('reference_sequences')->ignore(true)
                    ->insert(['prefix' => $prefix, 'year' => $year, 'last_number' => 0]);
                $row = $this->lock($prefix, $year);          //    lock again
            }
            $next = (int) $row->last_number + 1;
            $this->db->table('reference_sequences')->where('id', $row->id)
                ->update(['last_number' => $next]);          // 3. save
            $this->db->transCommit();
        } catch (\Throwable $e) {
            $this->db->transRollback();
            throw $e;
        }
        return sprintf('%s-%d-%04d', $prefix, $year, $next);
    }

    private function lock(string $prefix, int $year): ?object
    {
        return $this->db->query('SELECT id, last_number FROM reference_sequences'
            . ' WHERE prefix = ? AND year = ? FOR UPDATE', [$prefix, $year])->getRow();
    }
}
FORMAT

{PREFIX}-{YYYY}-{0000}

The counter restarts every year — UNIQUE(prefix, year).

WHY FOR UPDATE?

Two simultaneous applications must not get the same number. The row stays locked until commit.

💡
Do not use MAX(id) + 1 — it fails under concurrent load.
⚠️
FOR UPDATE first, INSERT IGNORE only when the row is missing. Reversed → S + X locks → deadlock (1213).

Query mentah di sini selamat kerana menggunakan binding (?), bukan cantuman input. Servis yang sama digunakan untuk PAS-2026-0001 pada Hari 7. Transaksi bersarang dalam CI4 selamat — hanya transaksi paling luar yang commit. Tekankan tertib: FOR UPDATE dahulu; INSERT IGNORE pada baris sedia ada mengambil kunci S dan dua request serentak akan deadlock. Templat penuh ada cuba semula untuk ralat 1213/1205.

class SlotAvailabilityService
{
    /** BR-TLK-01 */
    public function hasOverlap(
        int $slotId, string $start, string $end, ?int $except = null
    ): bool {
        $q = db_connect()->table('slot_bookings')
            ->where('slot_id', $slotId)
            ->whereIn('status', [
                BookingStatus::Pending->value, BookingStatus::Approved->value,
            ])
            ->where('start_date <=', $end)
            ->where('end_date >=', $start);

        if ($except !== null) {
            $q->where('id !=', $except);
        }

        return $q->countAllResults() > 0;
    }
}

Approve a booking: check, lock, update, log — atomically

app/Services/BookingService.phpphp
public function approve(int $bookingId, int $approverId): void
{
    $db = db_connect();
    $db->transException(true)->transBegin();
    try {
        $booking = $this->bookings->find($bookingId) ?? throw new \DomainException('Tempahan tiada.');
        $from    = BookingStatus::from($booking->status);
        if (! $from->canTransitionTo(BookingStatus::Approved)) {
            throw new \DomainException('Peralihan status tidak sah.');
        }
        $db->query('SELECT id FROM parking_slots WHERE id = ? FOR UPDATE', [$booking->slot_id]);   // BR-TLK-05
        if ($this->availability->hasOverlap((int) $booking->slot_id, $booking->start_date, $booking->end_date, except: $bookingId)) {
            throw new \DomainException('Slot telah diluluskan untuk tempahan lain.');                // BR-TLK-01
        }
        $this->bookings->update($bookingId, ['status' => BookingStatus::Approved->value,
            'decided_by' => $approverId, 'decided_at' => date('Y-m-d H:i:s')]);
        $this->logs->record('TLK', $bookingId, $from, BookingStatus::Approved, $approverId);
        $db->transCommit();
    } catch (\Throwable $e) {
        $db->transRollback();
        throw $e;
    }
    StatisticsService::forget();   // dashboard cache (Day 10)
}

One gate for every status transition

app/Services/PassWorkflowService.phpphp
public function transition(int $id, PassStatus $to, int $actorId, ?string $remarks = null): void
{
    $app  = $this->apps->find($id) ?? throw new \DomainException('Permohonan tiada.');
    $from = PassStatus::from($app->status);
    if (! $from->canTransitionTo($to)) {                                            // BR-PAS-01
        throw new \DomainException("Tidak boleh ubah {$from->value} ke {$to->value}.");
    }
    if ($to === PassStatus::Rejected && mb_strlen(trim($remarks ?? '')) < 10) {        // BR-PAS-03
        throw new \DomainException('Catatan penolakan minimum 10 aksara.');
    }
    $stamp = match ($to) {
        PassStatus::UnderReview => ['reviewed_by' => $actorId, 'reviewed_at' => date('Y-m-d H:i:s')],
        PassStatus::Approved    => ['approved_by' => $actorId, 'approved_at' => date('Y-m-d H:i:s')],
        default                 => [],
    };
    $db = db_connect();
    $db->transStart();
    $this->apps->update($id, ['status' => $to->value] + $stamp);
    $this->logs->record('PAS', $id, $from, $to, $actorId, $remarks);                  // BR-PAS-05
    $db->transComplete();
    StatisticsService::forget();
}

Controller ReviewController hanya memanggil transition() dengan status sasaran. Semakan kebenaran (siapa boleh ke status apa) dibuat di controller dengan auth()->user()->can('pas.approve') sebelum memanggil service, di samping filter laluan.

public function bookings(array $f): BaseBuilder
{
    $q = $this->db->table('slot_bookings b')
        ->select('b.ref_no, z.name AS zone, s.slot_no')
        ->select('s.category, b.start_date, b.end_date')
        ->select('b.status')
        ->join('parking_slots s', 's.id = b.slot_id')
        ->join('parking_zones z', 'z.id = s.zone_id');

    $map = ['from' => 'b.start_date >=', 'to' => 'b.end_date <=',
        'zone_id' => 's.zone_id', 'category' => 's.category',
        'status' => 'b.status'];
    foreach ($map as $key => $column) {
        if (! empty($f[$key])) {
            $q->where($column, $f[$key]);
        }
    }

    return $q->orderBy('b.start_date', 'DESC');
}

Service memulangkan builder, bukan hasil — supaya controller boleh memilih: paginate untuk HTML, get() penuh untuk eksport. $statuses = BookingStatus::cases() dihantar dari controller. Semua nilai penapis melalui Query Builder — tiada cantuman rentetan.

Day 9 · S2 — Aggregate · reference code

RPT-03: slot usage by zone

ReportService::usageByZone()php
public function usageByZone(int $year, int $month): array
{
    $from = sprintf('%04d-%02d-01', $year, $month);
    $to   = date('Y-m-t', strtotime($from));

    return $this->db->table('slot_bookings b')
        ->select('z.code, z.name')
        ->selectCount('b.id', 'total_bookings')
        ->join('parking_slots s', 's.id = b.slot_id')
        ->join('parking_zones z', 'z.id = s.zone_id')
        ->where('b.status', BookingStatus::Approved->value)
        ->where('b.start_date <=', $to)
        ->where('b.end_date >=', $from)
        ->groupBy(['z.code', 'z.name'])
        ->orderBy('total_bookings', 'DESC')
        ->get()->getResultArray();
}
Generated SQLsql
SELECT z.code, z.name,
       COUNT(b.id) AS total_bookings
FROM slot_bookings b
JOIN parking_slots s ON s.id = b.slot_id
JOIN parking_zones z ON z.id = s.zone_id
WHERE b.status = 'approved'
  AND b.start_date <= '2026-10-31'
  AND b.end_date >= '2026-10-01'
GROUP BY z.code, z.name
ORDER BY total_bookings DESC

public function xlsx(array $head, array $rows,
    string $name): DownloadResponse
{
    $book  = new Spreadsheet();
    $sheet = $book->getActiveSheet();
    $sheet->fromArray($head, null, 'A1');
    $sheet->fromArray(array_map('array_values', $rows),
        null, 'A2');

    $tmp = tempnam(WRITEPATH . 'cache', 'rpt');

    $data = file_get_contents($tmp);
    unlink($tmp);

}

class StatisticsService
{
    public const CACHE_KEY = 'stat_dashboard';

    public function dashboard(): array
    {
        return cache()->remember(self::CACHE_KEY, 600, fn (): array => [
            'kpi'        => $this->kpis(),
            'byMonth'    => $this->bookingsByMonth(),
            'passStatus' => $this->passStatusBreakdown(),
            'byZone'     => $this->usageByZone(),
            'trend'      => $this->applicationTrend(12),
        ]);
    }

    public static function forget(): void
    {
        cache()->delete(self::CACHE_KEY);
    }
}
